Zenith Devs

A modern business website showcasing web development services through clean design, responsive layouts, and a professional user experience.

Context
CSIT 201 — Final Project
01

The Challenge

Background: Zenith Devs was created as our final project for CSIT 201 – Web Development at Cebu Institute of Technology – University. Together with my project partner, Jay Canezo, we designed and developed an imaginary web development agency that showcases our services, previous work, and company information. Although the business is fictional, the goal was to build a website that follows real-world web development practices and could serve as a foundation for a future startup.

The Challenge: As first-year IT students, building a website from scratch was our biggest challenge. We had to learn how to plan the project, create wireframes, organize the website structure, write clean HTML, CSS, and JavaScript, and ensure the website remained responsive across different screen sizes. Since this was one of our first large web projects, every feature required experimentation, problem-solving, and continuous improvement.

The Goal: Design and develop a professional business website that effectively presents a web development agency, showcases its services and portfolio, and demonstrates our understanding of responsive web design and front-end development.

"Dream work makes the dream work."
02

Research & Ideation

Before writing the code, we explored modern agency websites to understand current design trends, layout structures, and user experience patterns. We analyzed how successful web development companies present their services, projects, and calls-to-action to potential clients.

Planning & Design:

  • Created low-fidelity wireframes to map the layout and content hierarchy before development.
  • Designed the user interface in Figma to establish consistent spacing, typography, and color usage.
  • Planned the navigation and page structure to provide visitors with an intuitive browsing experience.
  • Focused on creating a clean, modern aesthetic that reflects a professional software development agency.

Key Decisions: We intentionally chose HTML, CSS, and JavaScript instead of using frameworks to strengthen our understanding of core web technologies. This allowed us to gain practical experience with responsive layouts, semantic HTML, CSS styling, and JavaScript interactions.

03

Implementation

01
UI/UX & Wireframing
Started with hand-sketched wireframes before designing the complete interface in Figma. We established the visual hierarchy, spacing system, typography, and color palette to create a modern and professional business website that reflects the identity of a web development agency.
02
Core Development
Built the website using semantic HTML5, CSS3, and JavaScript. Developed reusable page sections, implemented responsive layouts using Flexbox and CSS Grid, added interactive animations, and optimized the interface for desktop, tablet, and mobile devices. To enable real client communication, the contact form was integrated with EmailJS, allowing project inquiries to be sent directly to our email without requiring a backend server.
03
Overcoming Roadblocks
One of the biggest challenges was creating a fully responsive layout while maintaining visual consistency across different screen sizes. We iteratively tested the website on multiple viewport sizes, adjusted spacing, typography, and component layouts, and refined the responsive behavior until the interface provided a smooth user experience on all devices.
04

The Final Solution

Zenith Devs became a modern business website that showcases a fictional web development agency. The website presents the company's services, portfolio, and business information through a clean, responsive interface designed to build credibility and encourage potential clients to learn more about the business.

Professional Landing Page
A modern homepage designed to introduce the agency, communicate its value proposition, and encourage visitors to explore our services.
About the Company
A dedicated section highlighting the company's mission, vision, expertise, and commitment to delivering modern web solutions.
Services Showcase
Clearly organized service offerings including web development, UI/UX design, responsive websites, and custom business solutions.
Responsive Experience
Optimized layouts and components that provide a seamless browsing experience across desktop, tablet, and mobile devices.
Portfolio Projects
A curated collection of sample projects demonstrating design quality, development skills, and problem-solving capabilities.
Contact & Inquiry
An easy-to-use contact section that encourages potential clients to reach out for consultations and future collaborations.

The Outcome: Zenith Devs successfully fulfilled the objectives of our CSIT 201 Web Development final project by transforming a business concept into a polished and responsive website. The project demonstrated our ability to apply UI/UX principles, front-end development techniques, and responsive design practices to create a professional web presence for a fictional web development agency.

What I Learned: Developing Zenith Devs strengthened my foundation in HTML, CSS, and JavaScript while teaching me how to transform ideas into a structured website through careful planning and UI/UX design. It reinforced the importance of semantic HTML, responsive layouts, reusable components, clean code organization, and collaborating effectively throughout the development process.

Next Steps: If I continue developing Zenith Devs, I would integrate a modern backend using Node.js and a database to support contact form submissions, quotation requests, user authentication, a content management system (CMS), and an admin dashboard. These improvements would transform the project from a front-end prototype into a fully functional business website capable of serving real clients.
