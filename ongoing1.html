Zenith Devs

A full-stack community platform built for developers to connect, collaborate, and grow.

Role
Full-Stack Developer & UI/UX Designer

April 2025
Tech Stack
HTML · CSS · JavaScript
Context
Academic Project at CIT-U
01

The Challenge

Background: Student developers at CIT-U lacked a centralized platform to showcase their projects, share knowledge, and connect with peers in a professional setting. Existing general-purpose social platforms weren't tailored for developer workflows, while platforms like GitHub lacked the community-first social layer that fosters collaboration.

The Problem: There was no dedicated space where student developers could post updates, share code snippets, highlight projects, and engage with a community that understood their context—all in one cohesive experience.

The Goal: Design and build a fully functional web application that serves as a developer-centric community hub, combining a clean social feed with portfolio-style project showcasing.

"Students were posting project updates in group chats and scattered forum threads. The goal was to centralize that energy into a single, purpose-built developer community platform."
02

Research & Ideation

User Insight: The target users were BS IT and CS students who were already building projects but had no polished way to present or discuss them beyond classroom demos. Interviews revealed they wanted something that felt professional but approachable—not corporate, not too casual.

Design & Architecture:

  • Mapped out user flows for onboarding, posting, and profile browsing using low-fidelity wireframes in Figma before writing a single line of code.
  • Settled on a component-based architecture in vanilla JavaScript with a modular CSS structure to keep the codebase maintainable without adding framework overhead.
  • Planned a flat content hierarchy—posts, profiles, and projects—to keep navigation simple and discoverable.

Key Decisions: Vanilla HTML/CSS/JS was chosen intentionally over React to deepen fundamentals while keeping the build lightweight. A dark, high-contrast UI was selected to align with the developer aesthetic the target audience identified with.

03

Implementation

01
UI/UX & Wireframing
Started with hand-sketched wireframes, then moved to Figma to establish the visual hierarchy, spacing system, and component library. Defined a strict 8px grid, a two-color palette (dark background + lime green accent), and typography pairing (Syne for headings, DM Sans for body) to achieve a polished developer aesthetic.
02
Core Development
Built the layout using semantic HTML5 with CSS custom properties for theming. Implemented dynamic post rendering using JavaScript DOM manipulation, local state management for UI interactions, and CSS animations for scroll-triggered reveals. Structured the codebase into logical modules: nav, feed, profile, and utility helpers.
03
Overcoming Roadblocks
The biggest challenge was achieving smooth scroll-triggered animations without a library. Initial attempts using scroll event listeners caused noticeable jank on mobile. The fix was switching to the IntersectionObserver API—a far more performant approach that only fires when elements enter the viewport, eliminating scroll event overhead entirely and resulting in buttery-smooth 60fps reveals across all devices.
04

The Final Solution

Zenith Devs delivers a dark-themed, performance-first developer community platform with a clean visual identity. The interface prioritizes readability and fast interactions with intentional use of whitespace, typography, and micro-animations.

The Outcome: Zenith Devs was successfully delivered as a complete academic project, earning recognition for its polished UI and attention to UX detail. The platform demonstrated that a compelling developer-community experience is achievable with pure web fundamentals—no frameworks required.

What I Learned: This project deepened my understanding of the IntersectionObserver API, CSS custom property systems, and the discipline required to build component-scale architecture without a framework. It also reinforced the importance of wireframing before coding—every hour in Figma saved two hours debugging layout issues.

Next Steps: If given more time, the natural evolution would be adding a real backend with Node.js and a database to support user authentication, persistent posts, and live notifications—transforming the static prototype into a production-ready platform.
